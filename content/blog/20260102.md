<h2 data-pm-slice="1 1 []">Research</h2>

- <a target="_new" rel="noopener" class="decorated-link" href="https://ethresear.ch/t/wormholes-and-the-cost-of-plausible-deniability/23728?utm_source=chatgpt.com">Wormholes and the cost of plausible deniability: </a> Highlights a core L1 constraint: Ethereum’s 160-bit address space makes “plausibly deniable” burn→mint constructions vulnerable to address-collision attacks, creating a risk of inflation under naive designs.
- <a target="_new" rel="noopener" class="decorated-link" href="https://ethresear.ch/t/integrated-in-protocol-distributed-history-and-state-storage/23522?utm_source=chatgpt.com">Integrated in-protocol distributed history and state storage: </a> Suggests placing block contents into blobs with commitments in block headers, allowing nodes to verify the chain using headers + data availability sampling (DAS) + proofs.

<h2 data-pm-slice="1 1 []">EIPs/Standards</h2>

- EIPs (Core, Networking, Interface)
  
  - <a target="_new" rel="noopener" class="decorated-link" href="https://eips.ethereum.org/EIPS/eip-7825?utm_source=chatgpt.com">EIP-7825 – Transaction Gas Limit Cap: </a> Implemented in Geth v1.16.2 for the upcoming Fusaka fork, introducing a protocol-level cap on transaction gas usage to improve execution predictability and mitigate worst-case block scenarios.
  - <a target="_new" rel="noopener" class="decorated-link" href="https://eips.ethereum.org/EIPS/eip-7934">EIP-7934 – RLP Execution Block Size Limit: </a> Implemented in Geth v1.16.2 for Fusaka, defining an explicit RLP-encoded execution block size limit to reduce networking and execution risk from oversized blocks.
- ERCs (Application Layer)
  
  - <a target="_new" rel="noopener" class="decorated-link" href="https://eips.ethereum.org/EIPS/eip-7773">EIP-7773 – ERC-7773: </a> Updated with EIP status decisions from ACDE 226, reflecting recent core developer discussion and agreement on its progression.
  - <a target="_new" rel="noopener" class="decorated-link" href="https://eips.ethereum.org/EIPS/eip-7688">EIP-7688 – ERC-7688: </a> Updated to fix field naming and improve wording, reducing ambiguity for implementers and indexers.
