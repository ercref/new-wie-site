## Highlight of the Week

- ACDE #228 set near-term Execution Layer direction for “Glamsterdam” devnet planning, including preferring a simpler contract-size bump approach (EIP-7954) over more complex code-size metering proposals.

## Eth R&D Protocol Call(s)

- [All Core Devs - Execution (ACDE) #228, January 15, 2026](https://github.com/ethereum/pm/issues/1862)
  
  - Glamsterdam upgrade:
    
    - Devnet-2 scope: discussed and flagged for revisit (incl. coordination concerns with CL-side changes) and to be finalized at the next testing-focused discussion.
    - Concerns raised about the large number of EIPs potentially being included in Glamsterdam
    - If targeting a June 2026 mainnet release, testnet releases would be needed by mid-April
  - EIP clarifications:
    
    - EIP-7778 (Block Gas Accounting without Refunds): Clarifications needed on CumulativeGasUsed in receipts and definitions of gasUsedForPaying and gasUsedForBlockLimit
    - EIP-8024 (Backward compatible SWAPN, DUPN, EXCHANGE): Discussion on behavior when code ends before immediate operand and proposal for a simpler version
    - EIP-7708 (ETH transfers emit a log): Pending PR with open questions about log address, topic values, and whether to include fee payment logs

## Research

- <a target="_new" rel="noopener" class="decorated-link" href="https://ethresear.ch/">Blob Analysis after Fusaka and BPO Updates</a>: empirical post-Fusaka / BPO study (MigaLabs) looking at blob utilization vs. targets and missed-slot correlations at higher blob counts, with a recommendation to pause further blob-parameter-only increases until miss rates normalize.
- <a target="_new" rel="noopener" class="decorated-link" href="https://ethresear.ch/">Recursive-STARK-based bandwidth-efficient mempool</a>: proposes periodically emitting a single recursive STARK attesting to validity of all still-valid objects a node has seen (rather than attaching large proofs per object).
- <a target="_new" rel="noopener" class="decorated-link" href="https://ethresear.ch/">Trust minimized transaction simulation using state proofs</a>: outlines a production-oriented approach for wallets to verify simulation prestate cryptographically (MPT proofs + multi-RPC stateRoot consensus) and then execute locally (e.g., with revm) to reduce blind trust in simulation APIs/RPCs.

## Layer 2

- Arbitrum positions itself as a stablecoin settlement layer, publishing a data-backed analysis highlighting concentration of stablecoin liquidity and transfer volume on Arbitrum and arguing this use case should guide future technical and ecosystem priorities.
- Optimism governance updates proposal to align OP token with Superchain success, revising details on Jan 15 to incorporate feedback, including mechanics for allocating 50% of Superchain revenue toward OP token buybacks and ecosystem alignment.

## Security

- Yo Protocol suffered a $3.71 million loss on January 14, 2026, when a vault operator fat-fingered a $3.84 million swap with broken slippage parameters. Only $112K came out the other side. The team quietly backstopped the loss and waited two days to mention it publicly.
- Truebit was drained for $26.2 million on January 12, 2026, through an unchecked integer overflow in unverified bytecode. This marks the first major hack of 2026, with the same attacker having hit Sparkle weeks prior.

## EIPs/Standards

- EIPs (Core, Networking, Interface):
  
  - [EIP-7778](https://eips.ethereum.org/EIPS/eip-7778): Block Gas Accounting without Refunds — Clarifies block gas accounting for receipts.
  - [EIP-7799](https://eips.ethereum.org/EIPS/eip-7799): Fee Payment Log — Adds a standardized fee payment log.
  - [EIP-8024](https://eips.ethereum.org/EIPS/eip-8024): Backward Compatible SWAPN, DUPN, and EXCHANGE — Specifies EVM behavior at the end of code execution.
  - [EIP-7825](https://eips.ethereum.org/EIPS/eip-7825): Transaction Gas Limit Cap — Defines an RPC method for capping transaction gas limits.
- ERCs (Application Layer):
  
  - [EIP-7932](https://eips.ethereum.org/EIPS/eip-7932): Pad sigrecover Return Value to 32 Bytes — Pads sigrecover output to 32 bytes.
  - [EIP-8096](https://eips.ethereum.org/EIPS/eip-8096): Double Repricing for Point Evaluation — Changes repricing to double.
  - [EIP-7916](https://eips.ethereum.org/EIPS/eip-7916): Merkleize to the Right — Updates SSZ merkleization to right-padding.
